# React Portfolio

A Vite + React portfolio project.

## Requirements

- Node.js 18+ recommended
- npm or pnpm

## Setup

```bash
cd react-portfolio
npm install
```

If you use pnpm:

```bash
cd react-portfolio
pnpm install
```

## Run locally

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Deployment

This app can be deployed to Vercel or any static host supporting Vite output.

- Build command: `npm run build`
- Output directory: `dist`

## Notes

- Keep `node_modules/` and local logs out of version control.
- If using GitHub, push this folder to your repository and connect it to Vercel for automatic deploys.
